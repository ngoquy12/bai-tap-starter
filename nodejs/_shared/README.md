# Tài nguyên dùng chung của môn NodeJS

- `node-template/`: khuôn dự án Node.js + Express + MySQL (đã ghim phiên bản thư viện). Dùng cho các lab trong `nodejs/session-02/lab_guide.md`: chép thư mục này thành thư mục dự án của bạn (ví dụ `rikkei-learn`).
- `db-learn/`: lược đồ và dữ liệu Rikkei Learn (`schema.sql`, `seed.sql`) cho Session 02. Chép vào thư mục `db` của dự án.
- `db-shop/`: lược đồ và dữ liệu Rikkei Shop (`schema.sql`, `seed.sql`) cho Session 01.
