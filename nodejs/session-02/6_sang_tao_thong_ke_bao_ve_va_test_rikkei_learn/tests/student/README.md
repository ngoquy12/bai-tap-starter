# Test của bạn

Đặt các tệp test do bạn tự viết ở thư mục này, tên tệp kết thúc bằng `.test.js` (ví dụ `my-api.test.js`). Yêu cầu và tiêu chí chấm nằm trong `de_bai_bai_tap.md`.

Gợi ý khung tệp: `require("supertest")`, `require("../../src/app")`, `require("../../src/db/pool")`, `require("../helpers/db")` (hàm `resetDatabase`) và `require("../helpers/token")` (hàm `tokenFor`).
